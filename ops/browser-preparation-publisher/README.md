# Portable preparation caller for one owning outer functions.exec

`caller.v8.js` defines global `createPublisherPreparationCaller(options)` and optionally exports it for isolated Node tests. It uses standard promises, setTimeout/clearTimeout and injected clock only. It does not require Node, AbortController, shared live store/load IPC, native cancel or a new browser. All preparation, final observations and dispatch for one continuation must stay in the SAME live factory/outer functions.exec context. functions.wait resumes the yielded outer cell; do not reconstruct prepared state in another isolate or pretend store is a live cross-isolate command queue. Process death stops the caller; durable server supervision and independently verified original terminal evidence remain separate requirements.

Options contain immutable safe binding IDs/generation, private planner callbacks and registered native callbacks. Planner callbacks bind EXISTING authenticated scoped MCP and hold private original key/lease in their local closure; no caller-selected identity/profile. heartbeat maps to ba_heartbeat_browser_preparation; preSubmit to normal admitted same-generation preSubmit; beginDispatch to ba_begin_terminal_browser_dispatch; markUncertain to existing same-attempt uncertainty. Never expose callback private arguments in logs/output.

Native ports prepareAndAwaitTerminal(registeredOperation,binding) and postAndAwaitTerminal(binding) MUST be actual owning registered-runtime callbacks, not a self-attested RPC boolean. They must verify the statically allowed registered read/prepare program versus the separately one-use Post operation and await actual native terminal metadata. Expected bounded observation: completed status, actual callID, inputSHA256 and actual terminal evidenceSHA256. A running/yielded/partial/tool-error result is NOT terminal; do not invent a wait/cancel API or mark custody. Correct native callable spelling and returned shape must be established from actual Publisher ALL_TOOLS and native receipts before binding. No default native implementation exists here. Root/sole Publisher supplies real supported bindings; main engineer never sends.

The caller keeps heartbeat alive during awaited preparation, permits one heartbeat in flight, bounds control RPC waits by their deadline/lease and cleans all timers. A lost permit/beginDispatch response is UNKNOWN and cannot be reissued. An uncertainty-record timeout is explicitly unconfirmed. Already-issued native read/prepare OR Post promises are tracked by stopNewActionsAndJoin, which naturally waits for actual completion rather than killing it. If the native promise remains pending, join remains pending: this is NOT quiescence. Returned observations always keep nativeQueueDrainProven/submissionPermitted false. Independent Owner terminal trust-anchor verification and durable generation fencing must precede any takeover; absence of permit/lease expiry alone is not stop proof. After possible permit/dispatch, reconciliation only, never a successor Post.

Actual Mac no-send UAT is NOT claimed by the Docker VM tests. Tests deliberately omit require/AbortController and use injected deterministic clocks. Execute on Tower only in existing reviewed Docker image; `node --test /source/tests/tdpd/browser-preparation-v8-caller.test.cjs` with source read-only/network none. Independent adversarial3cases are retained outside source in coordinator review directory and must also pass. No startup daemon/consumer or provider action is activated by loading this module.

Stop is checked after each awaited permit/dispatch control response and inside the deferred native callback immediately before invocation. A late valid control response cannot start Post after stop. Native Post OUTCOME wait is locally bounded by30seconds/currentlease; timeout records UNKNOWN and retains the real pending promise for join. This timeout is NOT native cancellation/completion or retry authority. Never use an outcome timeout as drain evidence.
