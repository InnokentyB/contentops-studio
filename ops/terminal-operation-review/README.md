# Local original-operation review

Run only on the computer holding the original native archive. Keep the archive and raw CUA programs local. The bundled Node program needs no package installation and does not open a browser, contact a provider or grant publication authority.

From an extracted portable bundle:

```
node ops/terminal-operation-review/review.cjs ARCHIVE THREAD_ID TURN_ID ORIGINAL_BROWSER_ID EXACT_PUBLISHED_PROFILE_URL TARGET_BINDING_JSON
```

The result is a non-authoritative local observation containing hashes and bounded classifications. An unsupported operation or external transport must be independently reviewed; it is not absence of submission. A failed command returns a static diagnostic without raw arguments. Control verification of the actual program version/run and a separate independent provider observation are still necessary. Do not use its four false authority flags as an admission token.
