# Подключение MCP для команды

Эта инструкция нужна владельцу проекта и коллегам, которые работают с Claude или Claude Cowork с разных устройств.

## Что нужно заранее

- Рабочий сервис `planner-mcp` на Railway.
- Открытый адрес MCP вида `https://<service>.up.railway.app/mcp`.
- Персональный MCP-доступ, созданный владельцем в настройках проекта. Railway-токены остаются только для обратной совместимости.
- Доступ владельца к настройкам проекта в планнере.

Проверить доступность можно в планнере: `Настройки` -> `MCP`. Статус должен быть `MCP работает`.

## Какой профиль выбрать

| Профиль | Для чего подключать | Чего не может делать |
|---|---|---|
| `planner` | планы недели, исследование, очередь и подготовка публикаций | переписывать готовый текст и публиковать без разрешённого инструмента |
| `writer` | черновики и правки текста | менять даты, каналы, темы и статусы |
| `art_director` | визуальные брифы и ревью | менять текст публикации |

Для одного человека можно подключить несколько профилей, но токен каждого профиля должен оставаться отдельным.

## Подключение Claude или Claude Cowork

1. В планнере откройте `Настройки` -> `MCP`.
2. Выберите карточку нужного профиля и скопируйте конфигурацию.
3. Владелец создаёт персональный доступ для участника проекта. Скопируйте показанный токен сразу: повторно он не отображается.
4. Замените шаблон токена на настоящий токен локально, не отправляя его в чат, git или документ.
5. В Claude откройте `Settings` -> `Connectors` -> `Add custom connector` и укажите URL профиля и bearer token.
6. Начните новый чат и отправьте:

```text
Прочитай bootstrap рабочей области, назови доступные инструменты и предложи следующий безопасный шаг для проекта.
```

Если Claude просит разрешение на действие с публикацией, подтвердите, что канал и конкретная задача выбраны верно.

## Первые сценарии

### Планирование

```text
Прочитай рабочую область проекта. Найди ближайшую неделю без утверждённой темы и предложи семь неповторяющихся тезисов. Ничего не публикуй и не меняй без моего подтверждения.
```

### Подготовка текста

```text
Найди задачи со статусом «готово к тексту», выбери одну ближайшую непубликованную задачу и подготовь черновик в языке её канала. Покажи результат до любых изменений статуса.
```

### Исследование Reddit

```text
Проверь доступность парсера, собери обсуждения по теме <тема>, затем кратко перечисли повторяющиеся боли, возражения и формулировки пользователей. Не создавай публикации без моего подтверждения.
```

## Безопасность и отзыв доступа

- Не используйте один общий токен для всех людей и профилей.
- Не вставляйте токены в промпты, скриншоты, документы или репозиторий.
- При потере устройства или уходе коллеги отзовите конкретный доступ в `Настройки` -> `MCP`. Redeploy не требуется.
- Токен закреплён за пользователем и проектом на сервере: параметры из вызова MCP не могут переназначить область доступа.
- Для проверки после замены токена используйте `Настройки` -> `MCP` и новый чат Claude.

## Если не подключается

1. Убедитесь, что URL заканчивается на `/mcp`, а не на `/health`.
2. Проверьте, что токен вставлен без пробелов и передан как `Authorization: Bearer <token>`.
3. Сверьте выбранный профиль с endpoint: `/mcp/planner`, `/mcp/writer` или `/mcp/art-director`.
4. Проверьте, что доступ не отозван, не истёк и выдан участнику текущего проекта.
5. Если карточка показывает `Не настроен`, создайте персональный доступ в этом же разделе.
