# Недельный MCP-контур в общей очереди публикаций

Отдельная канва автогенерации больше не является рабочим интерфейсом. Источник истины — `ContentItem` в общем плане публикаций.

1. Штаб вызывает `ba_start_week_autogeneration` с принятой темой недели, каналом и семью днями.
2. Planner создаёт семь датированных публикационных задач и возвращает `publication_task_id` каждой карточки.
3. Штаб проверяет темы через `ba_get_week_autogeneration` и принимает пакет командой `ba_decide_week_plan`.
4. Writer забирает `content_write`, сохраняет текст через `ba_complete_work_item`; reviewer принимает или возвращает редакцию.
5. Art Director принимает решение по визуалу. Если картинка не нужна, задача готова сразу; если нужна, готовность наступает после одобрения asset.
6. Статус `ready_for_execution` подхватывает встроенный scheduler. Коннектор публикует автоматически либо переводит задачу в `browser_required`.
7. Успешная публикация сохраняет permalink в `publication_fact`; карточка остаётся доступной в фильтре опубликованных и показывает контрольные точки метрик.

Для встроенного scheduler у `planner-app` должна быть переменная `ENABLE_INLINE_PUBLICATION_SCHEDULER=true`.
