# Управление стоимостью моделей

## Политика текстовых моделей

- Сильная модель (`STRONG_TEXT_MODEL`, по умолчанию `gpt-4o`) используется для авторов постов и тем.
- Экономичная модель (`LOW_COST_TEXT_MODEL`, по умолчанию `gpt-4o-mini`) используется для критиков, фиксеров, классификации и структурных проверок.
- Явная настройка модели у роли имеет приоритет над системным значением.
- Перед первым платным вызовом постового или тематического пайплайна проверяются все пары «модель — ключ провайдера». Ошибка конфигурации останавливает цепочку до генератора.
- GPT-5-модели вызываются через Responses API; старые chat-модели — через Chat Completions.

## Режимы изображений

| Режим | Модель | Назначение |
| --- | --- | --- |
| `preview` | `gemini-3.1-flash-lite-image` | дешёвый рабочий черновик; режим по умолчанию |
| `final` | `gemini-3.1-flash-image` | финальный визуал обычной публикации |
| `flagship` | `gpt-image-2` → vision critic → `gemini-3.1-flash-image` | только ключевые кампании и флагманские материалы |

Старые значения API `nano`, `gpt-image` и `full` временно поддерживаются для обратной совместимости. Новый UI отправляет только `preview`, `final` и `flagship`.

## Телеметрия

Каждый новый модельный вызов записывает в `planner.agent_runs`:

- provider и model;
- входные, выходные, кешированные и reasoning-токены, если провайдер их возвращает;
- задержку и provider request ID;
- расчётную стоимость для моделей с известным тарифом;
- успешный или неуспешный исход.

Сводка доступна владельцу проекта на вкладке «Настройки → Агенты» и через `GET /api/settings/model-usage?days=30`.

Стоимость является оценкой. Для модели без тарифа в локальной таблице вызов учитывается, но стоимость показывается как неизвестная. Это не заменяет счёт провайдера.

## Миграция и откат

Миграция `20260823180000_add_agent_run_cost_telemetry` только добавляет nullable-поля и индексы, а также меняет default provider для новых `ImageAsset`. Старые записи не переписываются.

При откате приложения новые поля можно оставить: предыдущая версия их не использует. Удалять колонки при срочном rollback не требуется.
