# Подключение VK

Для полной работы канала нужны два разных ключа. Кнопка подключения VK ID отвечает только за подтверждение личности и не выдаёт ключ для публикации.

## Ключи

| Поле в ContentOps Studio | Что указать | Для чего используется |
| --- | --- | --- |
| ID сообщества | Числовой ID без `club`, например `240051152` | Выбор сообщества |
| Ключ доступа сообщества | Ключ из управления сообществом | Публикация текста на стене |
| Пользовательский ключ VK API | Классический пользовательский ключ, не начинающийся с `vk2.` | Загрузка изображений и личные Stories |
| Ключ статистики | Пользовательский ключ с доступом к статистике, необязательно | Сбор метрик |

Ключи `vk2.*`, полученные через VK ID, нельзя помещать в поля публикации: VK принимает их для идентификации, но отклоняет публикационные методы.

## Проверка

1. Откройте `Настройки` → `Каналы` → нужный канал VK.
2. Укажите ID сообщества и оба публикационных ключа.
3. Сохраните канал.
4. Нажмите `Проверить доступ`.
5. Убедитесь, что интерфейс показывает готовность текста, изображений и Stories.

Не отправляйте ключи в чат и не храните их в Git. ContentOps Studio шифрует ключи перед записью в базу данных.
