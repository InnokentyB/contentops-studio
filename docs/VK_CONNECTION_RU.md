# Подключение VK

Канал использует разные способы доступа для ленты, изображений и персональных Stories. Planner сам обновляет VK ID OAuth-токен на Railway, поэтому его не нужно копировать или заменять вручную.

## Ключи

| Поле в ContentOps Studio | Что указать | Для чего используется |
| --- | --- | --- |
| ID сообщества | Числовой ID без `club`, например `240051152` | Выбор сообщества |
| Ключ доступа сообщества | Ключ из управления сообществом | Публикация текста на стене |
| Подключение VK ID | Кнопка `Подключить VK ID` в карточке канала | Персональные Stories; access/refresh token и `device_id` сохраняются зашифрованными |
| Пользовательский ключ VK API | Классический пользовательский ключ, не начинающийся с `vk2.`, необязательно | Загрузка изображений в посты сообщества, пока VK ID приложению не выдан доступ `photos` |
| Ключ статистики | Пользовательский ключ с доступом к статистике, необязательно | Сбор метрик |

Ключи `vk2.*`, полученные через VK ID, нельзя вручную помещать в поля ключа сообщества или классического user token. Ими управляет OAuth-подключение Planner.

## Обновление токена на сервере

После подключения через VK ID Planner сохраняет `device_id`, access token и `refresh_token` в зашифрованном виде. Перед публикацией Story приложение проверяет срок действия токена и при необходимости атомарно обновляет пару непосредственно на сервере Railway. Это не позволяет двум воркерам одновременно использовать один ротационный refresh token.

После установки этой версии существующий канал нужно один раз переподключить через кнопку `Переподключить VK ID`: у прежних подключений `device_id` не сохранялся. Успешное переподключение подтверждает server-side refresh и права администратора; доступность `photos` и `stories` проверяется отдельно через `Проверить доступ`.

## Проверка

1. Откройте `Настройки` → `Каналы` → нужный канал VK.
2. Укажите ID сообщества и ключ доступа сообщества.
3. Нажмите `Подключить VK ID` и завершите авторизацию профилем администратора сообщества.
4. Если нужны посты с изображениями, добавьте классический пользовательский ключ VK API.
5. Сохраните канал и нажмите `Проверить доступ`.
6. Убедитесь, что интерфейс отдельно показывает готовность текста, изображений и персональных Stories.

Не отправляйте ключи в чат и не храните их в Git. ContentOps Studio шифрует ключи перед записью в базу данных.
